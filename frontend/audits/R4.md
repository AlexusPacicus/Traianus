    or on the ground truth — so the reference is a direction also chosen without the neighbours
    (the argument K6 uses for its deciding null). J = 200 sets the Monte Carlo variance of the
    random-arm term (power), not validity; it is set by run time.
  Random horizontal axis, Σ-weighted (reference only) — as above with e_j replaced by
    g_j = X_cᵀ f_j / √1110 (X_c the centred EVAL matrix), 200 directions; D̄ reported, never used

    columns, so it returns y alone through the same z-scoring, distance and tie code (1-D
    Euclidean). Must give 15/15 for every q. A swapped pair (one note in the 384-d list and not
    in the observed list, one the other way) counts as a tie, not a failure, iff both notes'
    similarities to q lie within 1e-12 of the 15th-place similarity; this covers near-ties across
    ranks 14–16. Tolerance: float64 rounding of a unit-vector dot product and its z-transform is
    ≈ 1e-15 in similarity units, so 1e-12 leaves a margin of ≈ 1,000×. Ties and any note with
    G[q, ·] ≥ 1 − 1e-12 (near-duplicates) are counted and reported. Any other mismatch fails.
  Permutation control — per q, the neighbour list is the first 15 entries of
    rng.permutation(1109), indexed into the N − 1 notes other than q in index order, scored by
    the same recall function. Expected recall 225/1109 = 0.2029, per-q s.d. ≈ 0.445
    (hypergeometric), s.d. of the mean over 1,110 q ≈ 0.0133. Must fall within
    0.2029 ± 4 × 0.0133, widened to [0.149, 0.257]: a correct recall function falls outside with
    probability ≈ 6e-5 (normal two-sided tail at 4 s.d.), so a failure points at the code.
Dependence between notes: EVAL alternates chunks of a sequential text, so nearby q share
  neighbourhoods and their D_q are correlated. No single block length is derived; the decision
  runs over the grid L ∈ {1, 2, 5, 10, 20, 50}. For each L, EVAL is cut into ⌈1110 / L⌉
  contiguous blocks in index order (the last may be shorter). Grid ends: L = 1 is independence;
  L = 50 is the largest value of the 1-2-5 grid that leaves at least 20 blocks (23). Twenty is
  a declared minimum, not a derived one: with fewer resampling units the bootstrap distribution
  of the block mean takes few distinct shapes and percentile intervals tend to undercover.
  Requiring the rule to hold at every L makes the decision independent of any one length.
  Reported, not deciding: a ground-truth-only block length, L_gt = the smallest g in 1…100 with
  overlap(g) ≤ 2 × far, where overlap(g) = mean over i of |N15(i) ∩ N15(i + g)| / 15 in EVAL
  index order and far = the same mean over pairs with |i − j| ≥ 100; if no g ≤ 100 qualifies,
  L_gt is reported as null, read "> 100".
Draws: rng = numpy.random.default_rng(20260918) (PCG64), used in this order and nowhere else:
  E = rng.standard_normal((200, 384)) (row j is e_j); then, for q in EVAL index order,
  rng.permutation(1109); then, for each L in the grid in ascending order and for b = 1…10,000,
  K_b = rng.integers(0, n_blocks(L), n_blocks(L)) followed by J_b = rng.integers(0, 200, 200);
  then F = rng.standard_normal((200, 1110)) for the Σ-weighted reference; then, only when L_gt is
  not on the grid, the same bootstrap once more at L_gt for its interval (on the grid it reuses that
  L's interval and draws nothing).
Statistic: D_q = recall_operator(q) − mean over j of recall_random(q, u_j). For resample b at
  block length L, Q_b = the notes of the blocks in K_b with multiplicity (a block drawn twice
  counts twice), and D̄_b = mean over q in Q_b of
  [recall_operator(q) − mean over j in J_b of recall_random(q, u_j)], j with multiplicity too.
  D̄ = the same with all q and all 200 directions. D̄_b is computed from how many times each block
  and each direction was drawn, without materialising Q_b; a test checks it against explicit
  resampling with the same draws.
Rule: for each L, 95% interval = [sorted(D̄_b)[249], sorted(D̄_b)[9749]]. R4 holds (the operator
  scatters more than an arbitrary axis) iff the upper bound < 0 at every L in the grid;
  otherwise R4 does not hold. Resampling
  blocks of notes and directions makes the conclusion about an arbitrary horizontal direction
  orthogonal to q; resampling directions inside every note's term overstates the random arm's
  spread, so the interval is conservative — declared. B = 10,000: the rank of a 2.5% or 97.5%
  quantile has Monte Carlo s.d. √(B·0.025·0.975) ≈ 16 ranks; the neighbours sorted[233] /
  sorted[265] and sorted[9733] / sorted[9765] are reported to show that a decision does not hinge
  on Monte Carlo noise.
Reported, not deciding: retention = mean recall_operator / 15; the same statistic in 2D (x, y
